# 前端采集实时视频流进行人脸识别

## 1. 前言

**需求背景**：客户需要在用户 PC 机的 Chrome 浏览器 Web 系统界面上，启动实时视频流采集，获取视频帧图片进行人脸识别，从而检测用户是否在线以及是哪一位用户。同时还需要提供客户端程序（exe）方案以实现相同功能。

**核心目标**：
- 实时采集用户面部视频流
- 检测画面中是否存在人脸
- 将检测到的面孔与已知用户进行匹配识别
- 判断用户在线状态及身份
- 支持浏览器端和本地客户端两种部署方式
- 保障用户隐私和数据安全

---

## 2. 浏览器端人脸识别方案对比

### 2.1 方案一：face-api.js（纯前端）

**推荐理由**：face-api.js 是目前 GitHub 上最成熟的浏览器端人脸识别方案（18K+ star），基于 TensorFlow.js 构建，提供一站式的人脸检测、关键点定位、表情识别和身份识别能力，API 极其简洁。

#### 核心功能
| 功能 | 说明 |
|------|------|
| 人脸检测 | 三种检测器：SSD MobileNetV1 / TinyFaceDetector / MTCNN |
| 面部关键点 | 68 点面部关键点定位 |
| 表情识别 | 7 种表情（中性/高兴/悲伤/愤怒/恐惧/惊讶/厌恶） |
| 年龄/性别估计 | 辅助用户验证 |
| 人脸识别 | 128 维描述子匹配，LFW 基准准确率 99.38% |

#### 模型与性能
| 模型 | 大小 |
|------|------|
| Tiny Face Detector | 190 KB |
| SSD MobileNetV1 | 5.4 MB |
| MTCNN | 2 MB |
| 68 点关键点 | 350 KB |
| 表情识别 | 310 KB |
| 人脸识别 | 6.2 MB |
| **全部模型总计** | **约 14-15 MB** |

| 检测器 | 桌面端 (WebGL) | 移动端 |
|--------|---------------|--------|
| TinyFaceDetector | ~60 fps | ~15 fps |
| SSD MobileNetV1 | ~5-15 fps | 较慢 |

#### 优缺点

**优点**：
- API 极其简洁，几行代码即可实现完整流程
- 模型轻量化，TinyFaceDetector 仅 190KB
- 纯前端运行，无需网络，隐私保护最佳
- 社区成熟，浏览器兼容性好（Chrome/Firefox/Safari/Edge）

**缺点**：
- 基于较旧模型架构，检测精度落后于现代方案
- Windows 端性能较差（首帧 20-30 秒）
- Firefox 可能回退到 CPU 运行
- 维护活跃度下降（最后版本基于 tfjs 1.7）
- 对侧脸、遮挡、光照变化较敏感

#### 核心代码

```javascript
// 加载模型
const MODEL_URL = '/models';
await faceapi.loadSsdMobilenetv1Model(MODEL_URL);
await faceapi.loadFaceLandmark68Net(MODEL_URL);
await faceapi.loadFaceRecognitionModel(MODEL_URL);

// 视频采集
const video = document.querySelector('video');
await navigator.mediaDevices.getUserMedia({
    video: { width: 640, height: 480, facingMode: 'user' }
});

// 创建已知人脸数据库
const faceMatcher = async () => {
    const descriptions = [];
    for (const person of knownPersons) {
        const img = await faceapi.fetchImage(person.imageUrl);
        const desc = await faceapi.computeFaceDescriptor(img);
        descriptions.push(new faceapi.LabeledFaceDescriptor(person.name, [desc]));
    }
    return new faceapi.FaceMatcher(descriptions, 0.6);
};
const matcher = await faceMatcher();

// 实时检测循环
const canvas = document.querySelector('canvas');
canvas.width = 640;
canvas.height = 480;

setInterval(async () => {
    const detections = await faceapi.detectAllSizes(video)
        .withFaceLandmarks()
        .withFaceDescriptors();
    const resized = faceapi.resizeResults(detections, { width: 640, height: 480 });
    const ctx = canvas.getContext('2d');
    ctx.clearRect(0, 0, 640, 480);

    detections.forEach(det => {
        const label = matcher.findBestMatch(det.descriptor).label;
        const box = det.box;
        ctx.strokeStyle = (label !== 'unknown') ? 'green' : 'red';
        ctx.strokeRect(box.x, box.y, box.width, box.height);
        ctx.fillText(`${label} (${(1 - matcher.findBestMatch(det.descriptor).distance).toFixed(2)})`, box.x, box.y - 5);
    });
}, 100);  // ~10 fps
```

### 2.2 方案二：MediaPipe Face Detection（Google）

#### 核心功能
| 功能 | 说明 |
|------|------|
| 人脸检测 | BlazeFace 模型（短程/远程两种模式） |
| 468 点面部 landmarks | Face Mesh，高精度 3D 坐标 |
| 表情检测 | 不直接提供，可通过关键点自行推导 |
| 人脸识别 | **不支持**，需自行对接 |

#### 模型与性能
| 模型 | 大小 |
|------|------|
| BlazeFace (short range) | ~250 KB |
| Face Mesh (468点) | ~1.3 MB |

| 指标 | 桌面端 | 移动端 |
|------|--------|--------|
| BlazeFace 检测 | 30-60 fps | 15-30 fps |
| Face Mesh | 15-25 fps | 10-20 fps |

#### 优缺点

**优点**：
- Google 官方维护，持续更新
- BlazeFace 模型极快，适合实时检测
- Face Mesh 提供 468 点高精度关键点
- WASM 执行，性能稳定

**缺点**：
- **无内置人脸识别**（仅检测，不做身份匹配）
- 检测精度低于 face-api.js 的 SSD 方案
- 离线使用需自行托管模型
- 首次加载需从 CDN 下载 WASM（约 1-2 秒）

### 2.3 方案三：浏览器视频帧采集 + 后端 API 识别

#### 架构设计
```
[Chrome 浏览器] --JPEG帧--> [WebSocket/HTTP] --> [后端识别服务]
       ^                                              |
       |                                      [InsightFace/dlib]
       |                                              |
       <------ 识别结果 ---- 返回结果 -----------------+
       |
  [Canvas 渲染结果]
```

#### 前端视频采集代码

```javascript
// 获取摄像头流
const stream = await navigator.mediaDevices.getUserMedia({
    video: {
        width: { ideal: 640 },
        height: { ideal: 480 },
        facingMode: 'user'
    }
});
const video = document.getElementById('video');
video.srcObject = stream;
video.play();

// Canvas 抓帧（两种方式）

// 方式 A：WebSocket 实时推送（推荐，延迟低）
const ws = new WebSocket('ws://localhost:8080');
ws.binaryType = 'arraybuffer';
setInterval(() => {
    const canvas = document.createElement('canvas');
    canvas.width = 320;  // 降低分辨率加快传输
    canvas.height = 240;
    const ctx = canvas.getContext('2d');
    ctx.drawImage(video, 0, 0, 320, 240);
    canvas.toBlob(blob => ws.send(blob), 'image/jpeg', 0.7);  // 0.7 质量
}, 100);  // ~10 fps

// 方式 B：HTTP 轮询（简单但延迟高）
setInterval(async () => {
    const canvas = document.createElement('canvas');
    canvas.width = 640;
    canvas.height = 480;
    const ctx = canvas.getContext('2d');
    ctx.drawImage(video, 0, 0);
    const base64 = canvas.toDataURL('image/jpeg', 0.8);
    const resp = await fetch('/api/recognize', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ image: base64 })
    });
    const result = await resp.json();
    // 前端渲染结果...
}, 200);  // ~5 fps
```

#### 后端识别方案对比

| 方案 | 单次延迟(CPU) | 单次延迟(GPU) | 模型大小 | 准确率(LFW) | 适用场景 |
|------|-------------|--------------|---------|------------|---------|
| **dlib** | 50-100ms | 无 GPU | ~128D 描述子+检测器 ~10MB | 99.38% | 小规模(<1000人) |
| **InsightFace (ArcFace)** | 20-50ms | 5-10ms | ~20-50MB | 99.7%+ | 大规模生产级 |
| **face_recognition** | 70-150ms | 无 GPU | 同 dlib | 99.38% | 快速原型 |
| **facenet-pytorch** | 30-80ms | 30-80ms | ~90MB | 99.6% | 需 PyTorch 生态 |

**推荐后端方案：InsightFace + ONNX Runtime**
- 使用 ArcFace 嵌入，多民族准确率最高（MR-ALL 99.63%）
- 支持 GPU 加速（CUDA），吞吐量大
- 支持活体检测（blink detection）
- 模型 ONNX 格式，跨平台部署方便

#### 优缺点

**优点**：
- 最高识别准确率（InsightFace 99.7%+）
- 支持万人级人脸库检索
- 支持活体检测
- 前端零模型负担

**缺点**：
- 每帧需传输 JPEG（~10-30KB/帧），带宽消耗
- 需要后端服务器 + GPU 成本
- 用户视频数据上传到服务器，隐私风险最高
- 网络延迟影响实时体验

## 3. Python 桌面客户端方案（exe）

### 3.1 方案 A：PyQt/PySide6 + OpenCV + InsightFace（推荐）

#### 技术栈

| 组件 | 选型 |
|------|------|
| GUI 框架 | PySide6 / PyQt6 |
| 视频采集 | OpenCV (`cv2.VideoCapture`) |
| 人脸识别 | InsightFace (buffalo_l 模型) |
| 向量检索 | FAISS (ANN) |
| 活体检测 | MiniFASNetV2 |

#### 核心代码

```python
import sys
import cv2
import numpy as np
from insightface.app import FaceAnalysis
from PyQt6.QtWidgets import QApplication, QLabel, QMainWindow
from PyQt6.QtCore import Qt, QTimer
from PyQt6.QtGui import QImage, QPixmap

class FaceApp(QMainWindow):
    def __init__(self):
        super().__init__()
        # 初始化 InsightFace
        self.fa = FaceAnalysis(
            name='buffalo_l',
            root='./models',
            providers=['CPUExecutionProvider']
        )
        self.fa.prepare(ctx_id=0, det_size=(640, 640))

        # 加载已知人脸描述符
        self.known_descriptors = {}  # name -> 512-dim ndarray
        self.known_names = []
        self.known_vecs = []

        # 摄像头
        self.cap = cv2.VideoCapture(0)
        self.cap.set(cv2.CAP_PROP_FRAME_WIDTH, 1280)
        self.cap.set(cv2.CAP_PROP_FRAME_HEIGHT, 720)

        # 显示
        self.video_label = QLabel(self)
        self.video_label.setFixedSize(1280, 720)
        self.setCentralWidget(self.video_label)

        # 30fps 刷新
        self.timer = QTimer(self)
        self.timer.timeout.connect(self._update)
        self.timer.start(33)

    def _update(self):
        ret, frame = self.cap.read()
        if not ret:
            return

        # InsightFace 检测 + 特征提取
        faces = self.fa.get(frame)
        rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
        h, w, ch = rgb.shape

        for face in faces:
            bbox = face.bbox.astype(int)
            embedding = face.embedding  # 512-dim

            # 余弦相似度匹配
            best_name, best_score = self._match(embedding)

            color = (0, 255, 0) if best_name else (0, 0, 255)
            cv2.rectangle(frame, bbox[:2], bbox[2:], color, 2)
            cv2.putText(frame, f"{best_name} ({best_score:.2f})",
                        (bbox[0], bbox[1] - 10),
                        cv2.FONT_HERSHEY_SIMPLEX, 0.6, color, 2)

        # 转换显示
        rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
        q_img = QImage(rgb.data, w, h, ch * w, QImage.Format.Format_RGB888)
        self.video_label.setPixmap(QPixmap.fromImage(q_img).scaled(
            self.video_label.size(), Qt.KeepAspectRatio))

    def _match(self, embedding):
        if not self.known_vecs:
            return "Unknown", 0.0
        vecs = np.array(self.known_vecs)
        sim = vecs @ embedding  # 余弦相似度（假设已归一化）
        idx = np.argmax(sim)
        return self.known_names[idx], sim[idx]

if __name__ == '__main__':
    app = QApplication(sys.argv)
    w = FaceApp()
    w.show()
    sys.exit(app.exec())
```

```kotlin
class MainActivity : AppCompatActivity() {

    private lateinit var detector: FaceDetector

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        // 配置检测器
        val options = FaceDetectorOptions.Builder()
            .setPerformanceMode(FaceDetectorOptions.PERFORMANCE_MODE_FAST)
            .setLandmarkMode(FaceDetectorOptions.LANDMARK_MODE_ALL)
            .setClassificationMode(FaceDetectorOptions.CLASSIFICATION_MODE_ALL)
            .setMinFaceSize(0.15f)
            .enableTracking()
            .build()

        detector = FaceDetection.getClient(options)

        // CameraX 采集
        val analyzer = ImageAnalysis.Builder()
            .setBackPressureStrategy(ImageAnalysis.STRATEGY_KEEP_ONLY_LATEST)
            .setTargetResolution(Size(640, 480))
            .build()

        analyzer.setAnalyzer(Executors.singleThreadExecutor()) { imageProxy ->
            val image = InputImage.fromMediaImage(
                imageProxy.image, imageProxy.imageInfo.rotationDegrees
            )
            detector.process(image)
                .addOnSuccessListener { faces ->
                    for (face in faces) {
                        val bounds = face.boundingBox
                        val rotY = face.headEulerAngleY
                        val smile = face.smilingProbability
                        val trackingId = face.trackingId
                    }
                }
                .addOnCompleteListener { imageProxy.close() }
        }
    }
}
```

#### 核心代码（Kotlin + NCNN JNI）

```kotlin
class FaceActivity : AppCompatActivity() {

    private external fun ncnnInit(params: String, model: ByteArray): Int
    private external fun ncnnDetectFace(
        imageData: ByteArray, width: Int, height: Int,
        result: FloatArray
    ): Int
    private external fun ncnnSimilarity(v1: FloatArray, v2: FloatArray): Float
    private external fun ncnnRelease()

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        // 加载模型
        val paramsBytes = assets.open("det.params").readBytes()
        val modelBytes = assets.open("det.bin").readBytes()
        ncnnInit(String(paramsBytes), modelBytes)

        // CameraX 采集
        val analyzer = ImageAnalysis.Builder()
            .setTargetResolution(Size(640, 480))
            .setBackPressureStrategy(ImageAnalysis.STRATEGY_KEEP_ONLY_LATEST)
            .build()

        analyzer.setAnalyzer(Executors.singleThreadExecutor()) { imageProxy ->
            // 转换为 NCNN 输入格式
            val buffer = ...  // 图像数据
            val result = FloatArray(1000)
            ncnnDetectFace(buffer, imageProxy.image.width, imageProxy.image.height, result)
            // 解析检测结果，与已知人脸做余弦相似度匹配
            imageProxy.close()
        }
    }

    // 余弦相似度
    fun cosineSimilarity(a: FloatArray, b: FloatArray): Float {
        var dot = 0f, magA = 0f, magB = 0f
        for (i in a.indices) {
            dot += a[i] * b[i]
            magA += a[i] * a[i]
            magB += b[i] * b[i]
        }
        return dot / (sqrt(magA.toDouble()) * sqrt(magB.toDouble()) + 1e-8f).toFloat()
    }

    override fun onDestroy() {
        super.onDestroy()
        ncnnRelease()
    }

    companion object {
        init { System.loadLibrary("ncnn_jni") }
    }
}
```

### 5.3 隐私合规建议

1. **优先前端识别**：视频帧不离开设备，符合 GDPR/PIPL 数据最小化原则
2. **后端方案**：需明确告知用户数据上传，获取明确同意，提供数据加密传输（HTTPS/WSS）
3. **本地存储**：已知人脸特征向量存储在本地，不要上传至服务器
4. **数据保留**：不保存原始人脸图片，仅存储 512 维特征向量（不可逆）
5. **用户控制权**：提供关闭摄像头、删除面部数据的入口
