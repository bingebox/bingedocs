# 开源语音输入工具软件调研

## 1. 前言

手机端语音输入法和网页端语音输入法是AI时代的大势所趋，服务器端采用LLM大模型多模态语音识别功能来增强其功能，是目前AI语音的一大应用方向。

## 2. 手机端开源输入法软件

### 2.1 Sayboard

- **基于 Vosk 的离线引擎**：它使用 **Vosk** 语音识别库，这是一个高效的**离线语音识别引擎**。因此，它同样**完全离线，保护隐私**。
- **极致隐私保护**：虽然应用有 `INTERNET` 权限，但**仅用于下载语音模型**，且可以撤销。开发者明确承诺“**Sayboard 不会，也永远不会通过网络发送你的任何信息**”。
- **功能单一专注**：它的核心功能就是语音转文字输入法，不集成本地 LLM 进行文本后处理。

源代码: https://github.com/ElishaAz/Sayboard
在OPPO 9/Android 10系统上离线安装使用: 模型体积小（最小仅几十 MB），内存占用经过优化，低端设备也能流畅运行。离线安装成功，速度还可以，准确性一般，和飞书专业的没法比。

### 2.2 Transcribro

**Transcribro** 是一款完全离线的 Android 语音输入键盘，它的技术核心很纯粹：就是**在本地把语音转成文字**，然后帮你填到输入框里。
对手机性能要求较高，适合较新的 Android 设备。github下载太慢，没成功。
源代码：https://github.com/soupslurpr/Transcribro

### 2.3 BiBi Keyboard 

BiBi Keyboard（说点啥）是目前开源语音输入法中功能较为全面的一款，它通过“AI后处理”和“悬浮球”等设计，在提升输入效率方面做得不错。
本App软件负责采集语音样本，发放后台Qwen3大模型进行识别，转换为文本，然后返回给客户端进行显示。
源代码: https://github.com/BryceWG/BiBi-Keyboard
可以基于此源代码进行换皮肤，然后连接自建的vLLM+Qwen36大模型服务。
**我们的首选方案**

### 2.4 WhisperIMEplus

**WhisperIMEplus** 是一个完全离线的 Android 语音输入法，其核心技术围绕 OpenAI 的 Whisper 模型构建，并针对隐私保护和 Android 平台集成做了深度优化。
源代码: https://github.com/woheller69/whisperimeplus
### 2.5 Dictate Keyboard

**Dictate Keyboard** 是一个将**顶尖云端语音识别与强大AI文本处理**深度整合的 Android 键盘应用，其技术核心是灵活性和可定制性。
源代码: https://github.com/DevEmperor/DictateKeyboard

## 3. web端开源输入法软件

### 3.1 Vosk-browser 

内网轻量化首选，低配置浏览器流畅
源代码: https://github.com/alphacep/vosk-browser

### 3.2 Sherpa-ONNX Web

国内语音大厂方案，中文最强，推荐涉密内网
**核心优势** 
* 原生支持 WeNet、Paraformer、SenseVoice 国产中文模型，普通话 / 方言识别远超 Vosk； 
* WASM+ONNX 推理，CPU 速度极快，支持 int8 量化模型； 
* 流式实时语音输入，同时支持音频文件批量转写； 
* 跨端统一：Web/Windows/Android 共用一套模型，内网统一部署； 
* 开源 Apache2.0，国内团队维护，中文文档完善； 
* 支持静音自动截断、多轮连续录音，适配表单语音录入。 

**短板**
模型体积中等（80~200MB），前端打包需要处理 Wasm 静态资源跨域头。

**适用场景**
政务内网、企业封闭 Web 平台、需要高准确率中文识别、支持方言。

源代码: https://github.com/k2-fsa/sherpa-onnx
方案 A: WASM 端侧推理
方案 B: WebSocket 远程推理
**我们的首选方案**  我们正在快速做一个产品原型出来。

二进制安装包： https://github.com/k2-fsa/sherpa-onnx/releases/tag/v1.13.4
模型: https://github.com/k2-fsa/sherpa-onnx/releases/tag/asr-models

### 3.3 Transformers.js

源代码底层库: https://github.com/huggingface/transformers.js

## 4. windows端开源语音输入法软件

**CapsWriter-Offline** 是一款为 Windows 系统设计的**完全离线、低延迟、高准确率**的语音输入工具。
它的核心用法很简单：**按住 `CapsLock` 键或鼠标侧键说话，松开按键，识别出的文字就会自动输入到你当前光标所在的位置**。除了实时语音输入，它还支持将音视频文件拖拽到客户端直接转录生成 `srt` 字幕文件。
- **项目主页**： https://github.com/HaujetZhao/CapsWriter-Offline
- **程序下载页 (Releases)**： https://github.com/HaujetZhao/CapsWriter-Offline/releases
