## 2. 值得跟进的信号（与本机/公司业务相关）

1. **Rust 的 AI 基建地位坐实**：Nexus 用 Rust 写 GPU 多物理场仿真器、Rust 基金会 CEO 站台、同期办 Rust China Conference——印证《Rust语言与AI应用生态调研及学习路径》中"Rust 取代 Python 底下的 C/C++ 层"的判断。
2. **MCP 成为大会级基础设施**：字节 SPEAR 边缘 Agent 运维方案直接以 MCP 为接口；Hermes Agent 等 agent 框架的 MCP 路线获产业侧验证。
3. **KTransformers 值得单独立项调研**：消费级硬件跑全精度万亿 MoE，与 2080Ti 本地实验、内网 L20 部署场景高度相关。
4. **昇腾开源训练生态**是国产算力去 CUDA 化的正面路线，可对照 LLM/2026-07-22《从CUDA到SAIL-CANN-MXMACA》补充 CANN 侧进展。
5. **OpenCV 5 升级**：公司 jlface 人脸识别栈基于 OpenCV，5.x 迁移影响面需在升级前评估（关注 ABI 与 contrib 模块变化）。
