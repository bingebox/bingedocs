### 2.3 技术栈学习路径建议

#### 第一阶段：筑基（必须掌握）

```
Python → PyTorch → NLP基础 → Docker
```

1. **Python** — 79%的岗位需要，AI领域第一语言
2. **PyTorch** — 36%提及，但实际使用面更广（很多岗位不显式列出）
3. **Docker/容器化** — 30%，生产环境部署必备
4. **NLP基础** — 25%，理解Transformer、Attention机制

#### 第二阶段：核心（差异化竞争力）

```
Agent开发 → RAG → LangChain → 向量检索 → 微调
```

1. **Agent开发** — 58%，当前最热方向
2. **RAG** — 53%，企业落地首选方案
3. **LangChain** — 34%，Agent框架事实标准
4. **向量检索/Embedding** — 26%，RAG的核心组件
5. **大模型微调** — 26%，定制化能力

#### 第三阶段：进阶（高阶竞争力）

```
LangGraph → 多模态 → vLLM推理优化 → MLOps → 分布式
```

1. **LangGraph** — 15%，复杂Agent编排
2. **多模态** — 13%，图文/视频理解

4. **MLOps** — 8%，完整AI工程体系
5. **分布式/微服务** — 17%，大规模系统

#### 第四阶段：前沿（差异化王牌）

```
AI安全/红队 → 知识图谱 → AIGC → Rust/C++底层优化
```

## 三、工作内容分析

### 3.1 岗位类型分类

| 岗位类型 | 占比 | 核心职责 |
|----------|------|----------|
| **AI Agent开发** | ~25% | Agent平台架构、RAG引擎、工作流编排、工具调用 |
| **大模型微调/训练** | ~15% | SFT/DPO、模型适配、评估对齐 |
| **AI应用开发** | ~20% | 将AI能力集成到业务系统、API开发、前后端 |
| **计算机视觉** | ~15% | 目标检测、图像分割、OCR、视频分析 |
| **AI平台/基础设施** | ~10% | 模型部署、推理服务、GPU资源管理 |
| **AI安全/评测** | ~5% | 红队测试、评估体系、内容安全 |
| **AI全栈/架构师** | ~5% | 技术选型、架构设计、团队管理 |
| **其他** | ~5% | Prompt工程、多模态、AIGC等 |

### 3.2 典型工作内容拆解

#### 场景1：AI Agent开发工程师（最常见的岗位）

```
1. Agent平台架构设计（服务拆分、模块边界）
2. RAG引擎开发（向量检索 + Embedding + Rerank）
3. 工具调用与Function Calling
4. 工作流编排（LangGraph/LangChain）
5. Prompt设计与优化
6. 评测体系搭建（评估Agent能力）
7. API服务开发（FastAPI）
8. 部署上线（Docker + 容器编排）
```

#### 场景2：大模型微调工程师

```
1. 数据收集与清洗（指令数据集）
2. SFT监督微调
3. DPO/RLHF对齐
4. 评估与迭代
5. 模型部署（vLLM/ONNX）
6. 推理服务优化
```

#### 场景3：AI应用开发工程师

```
1. 业务需求分析 → AI方案设计
2. 后端API开发（FastAPI/Java/Spring）
3. 模型调用与集成（OpenAI API / 本地部署模型）
4. 前端交互（流式输出、对话界面）
5. 数据对接（数据库、消息队列）
6. 性能优化（异步、缓存、限流）
```

## 五、学历与经验要求

### 5.1 学历要求

| 学历 | 占比 | 说明 |
|------|------|------|
| 硕士 | ~85% | 算法/研究岗硬性要求 |
| 本科 | ~4% | 偏工程/应用岗可接受 |
| 博士 | ~11% | 前沿研究/架构师岗 |

**核心发现：硕士是AI岗位的"入场券"，尤其是算法/研究类岗位。**

### 5.2 经验要求

| 经验 | 占比 | 说明 |
|------|------|------|
| 5年以上 | ~96% | 绝大多数岗位要求5年+经验 |
| 1-3年 | ~2% | 少数初级/应届岗 |
| 不限 | ~2% | 极个别 |

**这是一个"高门槛"市场。** 大多数AI岗位要求5年以上经验，且需要完整的生产系统Owner经验。

### 5.3 经验要求拆解

```
5年+经验的真实含义：
├── 至少1-2个完整生产系统从0到1的Owner经验
├── 系统架构设计能力（不是只会调API）
├── 性能调优经验（并发、延迟、资源管理）
├── 团队协作与代码评审经验
└── 行业领域知识（金融/医疗/制造等）
```

## 六、AI工程师修炼路线图

### 6.1 给初学者的建议（0-2年）

```
目标：进入AI行业，打好基础
优先级：Python → PyTorch → 基础机器学习 → 动手做项目

1. 熟练掌握Python（数据结构、异步编程、类型提示）
2. 掌握PyTorch（Tensor操作、Autograd、nn.Module）
3. 学习机器学习基础（sklearn、经典算法）
4. 学习深度学习基础（CNN、RNN、Transformer）
5. 做1-2个完整的端到端项目（从数据到部署）
6. 学习Docker基础
```

### 6.2 给转行者的建议（2-5年）

```
目标：成为独立的AI开发者
优先级：RAG → Agent → LangChain → 模型微调

1. 深入RAG技术栈（向量数据库 + Embedding + Rerank）
2. 掌握至少一个Agent框架（LangChain或LangGraph）
3. 学习大模型微调（LoRA/QLoRA实战）
4. 学习Prompt工程（CoT、Few-shot、Function Calling）
5. 掌握模型部署（ONNX + vLLM）
6. 学习评测方法（构建评估体系）
7. 在某个行业领域深耕（金融/医疗/制造）
```

### 6.3 给资深工程师的建议（5年+）

```
目标：成为架构师/Tech Lead
优先级：架构设计 → 多模态 → 推理优化 → MLOps

1. 系统设计能力（微服务、分布式、高可用架构）
2. 多模态能力（图文、视频、音频）
3. 推理服务优化（vLLM、TensorRT、INT8量化）
4. MLOps体系建设（模型监控、实验追踪、CI/CD）
5. AI安全（红队测试、对抗防御）
6. 团队管理与技术选型
7. 前沿追踪（Agentic、多Agent协作）
```

### 6.4 通用建议（无论哪个阶段）

1. **深耕一个行业领域** — 纯技术不够，需要领域知识
2. **建立生产级工程能力** — 会调API不等于会做产品
3. **关注AI编程工具** — Cursor/Claude Code/Copilot已成标配
4. **保持学习前沿** — AI领域变化极快，每月至少读2-3篇paper
5. **参与开源社区** — 对职业发展有帮助
6. **积累作品** — GitHub、技术博客、社区分享

## 七、市场趋势判断

### 7.1 当前 hottest 方向

1. **Agent开发**（58%提及） — AI Agent平台是当下载体
2. **RAG**（53%提及） — 企业落地首选方案，比纯微调更实际
3. **大模型微调**（26%提及） — 定制化需求持续增长
4. **多模态**（13%提及） — 图文/视频理解是下一个突破点

### 7.2 新兴方向

1. **AI安全/红队** — 合规需求驱动，从0到1
2. **AI编程工具链** — Cursor/Claude Code生态
3. **推理优化** — vLLM/SGLang，降本增效的关键
4. **MLOps** — AI工程化到一定阶段后的必然需求

### 7.3 趋势总结

```
2026年AI岗位的关键词：
├── Agent（不是简单的对话机器人，是能做决策的智能体）
├── RAG（企业落地的黄金标准）
├── 微调（定制化是刚需，不是锦上添花）
├── 工程化（从PoC到生产的最后一公里）
├── 评测（没有评估就没有优化）
└── 行业化（通用大模型+行业know-how = 竞争力）
```

## 八、一句话总结

> **2026年的AI工程师 = 5年+工程经验 + Agent/RAG实战 + 微调能力 + 行业Know-How + 生产级部署能力。**
>
> 纯调API的时代已经结束，"会调OpenAI API就能做AI"的认知已经过时。企业需要的是**能独立完成从设计到上线全链路**的AI工程师。
