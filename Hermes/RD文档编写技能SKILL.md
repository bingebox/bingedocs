# RD 项目方案标准模板

从 RD Word 文档标准表格提取的完整 Markdown 模板，表格字段保持 2 列格式，正文内容转为章节格式。所有原表格项无一遗漏。

## When to Use

- 编写新的 RD 项目方案文档时，作为填空模板
- 从已有 RD 文档（如 RD16）提取模板结构后复用
- 需要统一所有 RD 项目的表格元数据和章节格式

## Prerequisites

- RD 项目原始参考文档（如 `2025RD项目16 -20250808-liangbing.docx`）

## How to Run

通过 `skill_view` 加载此技能，复制下方模板内容到新 `.md` 文件逐项填写。

## Quick Reference

模板包含 12 项，对应原表格全部字段：

| 序号 | 字段名 | 格式 |
|------|--------|------|
| 1 | 研发活动名称 | 表格（2 列） |
| 2 | 起止时间 | 表格（与名称同行） |
| 3 | 技术领域 | 表格（2 列） |
| 4 | Key | 表格（2 列） |
| 5 | 技术来源 | 表格（2 列） |
| 6 | 知识产权编号及名称 | 表格（2 列） |
| 7 | 研发经费总预算 | 表格（含子项） |
| 8 | 研发经费近3年总支出 | 表格（含第1/2/3年） |
| 9 | 参与人员名单（研发人员） | 表格（2 列） |
| 10 | 立项目 | 章节（5 段结构） |
| 11 | 组织实施方式 | 章节（2-3 条结构） |
| 12 | 核心技术及创新点 | 章节（核心技术编号 + 创新点编号） |
| 13 | 取得的阶段性成果 | 章节 |

## Procedure

### Step 1: 加载模板

```
skill_view(name='rd-project-template')
```

### Step 2: 复制模板到新文件

将下方"模板内容"部分完整复制，保存为新项目 `.md` 文件（如 `rd01.md`）。

### Step 3: 逐项填写

按"填写说明"逐行填写每个字段。


## 填写说明

### 表格字段（1-9）

| 字段 | 填写要求 |
|------|----------|
| 研发活动名称 | 项目名称，如"异步分级队列限流控制技术" |
| 起止时间 | 格式"YYYY.MM-YYYY.MM，X-X人月" |
| 技术领域 | 如"电子信息-信息安全技术-应用安全技术" |
| Key | 如无留空 |
| 技术来源 | 企业自有技术 / 合作开发 / 引进消化 |
| 知识产权编号及名称 | 软著/专利编号及名称，如无留空 |
| 研发经费总预算 | 单位万元 |
| 研发经费近3年总支出 | 单位万元，含第1/2/3年明细 |
| 参与人员名单 | 研发人员姓名 |

### 章节字段（10-13）

| 字段 | 填写要求 |
|------|----------|
| 立项目 | 5段式：业务价值→限制条件→风险→痛点→解决方向 |
| 组织实施方式 | 研究方式+资金来源，各1条 |
| 核心技术 | 总体描述+编号列表，5-7条 |
| 创新点 | 编号列表，3-5条 |
| 阶段性成果 | 应用方向+拟申报知识产权 |

## Pitfalls

- **表格列数可能变化**：原表格中不同行的列数不一致（如第 1 行 4 列、第 4 行 5 列、第 5-7 行 7 列），创建新模板时需按实际字段调整列数。
- **同一单元格多字段**：如"立项目的及组织实施方式"在同一单元格内包含两个大章节，应拆分为独立子章节。
- **经费表格跨行**：第 5-7 行共用前 4 列（表头），模板需体现这种嵌套关系。
- **核心技术编号可能变化**：原 RD16 有 6 项核心技术和 4 项创新点，新项目可能数量不同，模板应使用编号列表便于增删。
- **Key 字段可能为空**：部分项目无 Key 值，留空即可。

## Verification

填写完成后，逐项核对模板中 12 项是否均有内容（或明确留空），表格结构与章节格式不混淆。
