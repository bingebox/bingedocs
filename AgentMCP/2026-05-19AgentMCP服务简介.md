## 2. 对已有企业业务系统HTTP API接口进行mcp包装

npx @ivotoby/openapi-mcp-server \
  --api-base-url http://gateway:10090 \
  --openapi-spec http://gateway:10090/ncdw-web-bill/v2/api-docs \
  --headers "apptoken:8feaa818-56dd-4c95-848b-ace88bdaa380,User-Id:1,Content-Type:application/json" \
  --transport http \
  --port 8800
